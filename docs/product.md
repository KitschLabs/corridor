# Corridor MVP 제품 명세

제품 목적·범위는 [README](../README.md), 확정과 제안의 구분은
[결정 기록](decisions.md)을 따른다. 아래 세부 UX 수치는 구현 기본안이다.

## 핵심 사용자 흐름

1. Google 또는 Magic Link로 로그인하고 팀을 생성하거나 초대 링크로 가입한다.
2. My Work에서 관련 업무의 변화를 확인하고 개인 노트를 작성한다. 노트는 팀원에게 보이지 않는다.
3. Team Focus에서 Mission·현재 목표·연결된 Workstream을 확인한다.
4. 필요한 내용만 선택하고 팀 업데이트의 내용·이미지를 검토해 발행한다.
5. 팀원이 Mission Control과 Workstream에서 변화를 이해하고 댓글로 논의한다.

팀 보고를 위해 개인 기록 전체를 제출하거나 매일 일지를 작성할 필요는 없다.

## 공통 Navigation과 정보 구조

모든 역할에 Mission Control, My Work, Workstreams, Team Focus의 동일한 탭을 제공한다.
역할에 따라 탭을 숨기거나 관리자용 내비게이션으로 분리하지 않는다.
개인 데이터는 작성자만, 발행된 팀 데이터는 현재 조직 구성원 모두가 조회한다.
수정·삭제·조직 관리 동작은 기존 권한 표를 따른다. 탭 접근과 데이터 변경 권한은 별개다.

| 탭 | 목적 | 주요 구성 |
| --- | --- | --- |
| Mission Control | 팀 전체의 현재 상황과 중요한 문제 파악 | Goals, Attention Needed, Workstreams별 최근 변경 타임라인 |
| My Work | 개인의 작업 맥락 복원과 기록 관리 | My Workstreams, Personal Notes, Captured Activities |
| Workstreams | 업무별 맥락·상태·변화 탐색 | 전체 목록, Goal/PIC/참여자/상태 필터, Context, Current State, Timeline, Discussion |
| Team Focus | 팀이 무엇을 왜 달성하려는지 공유 | Mission, Current Goals, Related Workstreams |

모든 탭에서 Global Search, Organization Switcher, Profile & Settings를 제공한다.
Markdown Editor와 사용자·Workstream 멘션은 각 탭의 관련 작성 화면에서 같은 컴포넌트를 사용한다.
검색 범위는 현재 조직의 Workstream·발행 Update·Team Goal 및 본인 노트이며,
팀 미연결 개인 노트도 본인에게만 검색된다. 조직 전환 시 검색·선택·필터를 초기화한다.

### Mission Control

최상단 Goals는 목표를 동등한 카드로 표시하고 전체 편집은 Team Focus 탭으로 연결한다.
초기에는 모든 목표의 업무를 보여준다. 카드 하나를 선택하면 연결된 Workstream·Attention·Recent Changes만
표시하고 카드 윤곽선으로 선택을 강조한다. 아이콘은 항상 타겟으로 표시하며 같은 카드를 다시 누르면 선택을 해제한다.
Goal에는 PIC·참여자 프로필을 표시하지 않는다. Mission Control에서는 PIC를 행 제목에만 표시하고 Workstream 카드의 PIC·참여자 표시는 생략한다.
이는 등록된 참여 관계이며 고관여도 분석 결과가 아니다. 참여자가 없으면 참여자 영역은 생략한다.
목표가 없는 경우 빈 상태를 표시하며 목표 미연결 업무는 전체 보기에서 확인한다.
Attention Needed는 팀 전체의 결정·조율·주목이 필요한 신호를 보여준다. 예: 디자인 정체가
회원가입 개발을 막는 의존성 병목, 특정 팀원에게 몰린 업무, 팀 차원의 우선순위 결정과 위험.
개별 업데이트의 `blocker`·`decision` 유형만으로 자동 노출하지 않는다. 팀 영향과 검토 필요성이 있어야 한다.
각 항목에는 상황, 팀에 미치는 영향, 근거, 팀에서 논의할 내용, 관련 팀원·Workstream을 표시한다.
한 신호가 여러 Workstream·Goal에 연결될 수 있으며 관련 Goal 중 하나를 선택해도 표시한다.
Goal 미연결 팀 신호는 전체 보기에서 제공한다. 관련 Workstream의 Discussion으로 이동해 논의한다.
초기 프리뷰는 별도 수동 등록 예시 신호를 사용한다. 실제 정체 기간·의존성·업무 편중 자동 분석은 미구현이다.
할당 수는 현재 조직 안에서 PIC와 참여를 구분하며 개수만으로 과부하나 개인 성과를 판정하지 않는다.
실제 연동 시 근거 시점과 확인 필요/해결 상태를 관리하고 해결된 항목은 제외한다.
Workstreams는 업무 이름·한 줄 소개 아래에 해당 업무의 최근 변경 최대 2개를 최신순 타임라인으로 표시한다.
PIC별로 한 행을 만들고 같은 PIC의 업무 카드를 가로로 배치한다. 각 행은 독립적으로 좌우 스크롤한다.
터치·트랙패드·키보드와 좌우 버튼을 지원하며 Goal 변경 시 각 행의 첫 카드부터 표시한다.
기존 Workstream Overview와 Recent Changes는 이 섹션으로 통합한다. 변경을 클릭하면 상세를 확인하고,
업무 이름을 클릭하면 Workstream 상세로 이동한다. 변경이 없으면 빈 상태를 표시한다.
완료율이나 개인 성과 지표, 독립 Activity 탭은 만들지 않는다.

### My Work

My Workstreams는 본인이 PIC 또는 참여자인 업무다. 각 업무의 최신 변경 1개를 표시하며,
최신 작성자가 타인이면 본인의 마지막 변경도 별도로 표시한다. 최신 변경이 본인의 것이면 중복하지 않고,
본인 기록이 없으면 최신 변경만 표시한다. 변경을 클릭하면 상세를 확인한다.
Captured Activities는 본인만 볼 수 있는 수집 영역이다. 에이전트 연결 전에는 비어 있는 상태와
개인 메모 작성 동선을 제공하며, 수동 업데이트를 자동 수집 결과로 표시하지 않는다.
자동 활동이 연결되어도 검토·공유 전에는 팀 데이터로 전환하지 않는다.

에이전트 자동 추적·분석은 이번 구현 범위 밖이다. 자동 Attention Needed는 추후 입력원으로
연결하고 초기에는 사람이 작성한 상태·업데이트를 사용한다.

## 화면·경로 기본안

| 경로 | 화면 | 핵심 동작 |
| --- | --- | --- |
| `/login` | 로그인 | Google / Magic Link, 로케일 선택, 실패·재시도 |
| `/auth/callback` | 인증 콜백 | 검증 후 허용된 내부 경로로 이동 |
| `/onboarding` | 첫 진입 | 이름 설정, 팀 생성 또는 초대 가입 |
| `/invite/[token]` | 초대 수락 | 로그인, 만료·취소·이미 가입 처리 |
| `/o/[orgId]/mission-control` | Mission Control | 팀 상황, 주의 항목, 업무 개요, 최근 변화 |
| `/o/[orgId]/my-work` | My Work | 관련 업무·새 변화·비공개 노트·수집 영역 |
| `/my/notes/[noteId]` | 개인 노트 상세 | 편집, 저장 상태, 이미지, 공유 |
| `/o/[orgId]/focus` | Team Focus | Mission, 활성 목표, 연결 업무 |
| `/o/[orgId]/workstreams` | Workstream 목록 | 상태·PIC, 생성 |
| `/o/[orgId]/workstreams/[id]` | Workstream 상세 | 상황·방향, 참여자, 업데이트, 토론 |
| `/o/[orgId]/members/[userId]` | 팀원 프로필 | 표시 이름·팀 역할·참여 Workstream |
| `/o/[orgId]/settings` | 조직 설정 | 조직 정보, 초대, 멤버·역할, 탈퇴 |
| `/settings/profile` | 개인 설정 | 이름, ko/en 선택, 로그아웃 |

조직 선택은 앱 셸에서 제공한다. URL에 조직 ID가 있어도 멤버십 검증을 통과해야 한다.
데스크톱은 고정 내비게이션, 모바일은 접을 수 있는 내비게이션을 기본안으로 한다.

레이아웃 프리뷰에서는 `/mission-control`, `/my-work`, `/workstreams`, `/team-focus`와
`/workstreams/[id]`를 사용한다. 조직은 샘플 선택기로 전환한다. 실제 인증·조직별 URL은
Foundation에서 위 경로 계약으로 연결한다.

## Personal Notes

노트 제목은 선택이다. 빈 제목은 첫 본문 줄을 목록 제목으로 사용하며,
본문도 없으면 `제목 없는 노트 / Untitled note`로 표시한다.
새 노트는 서버에서 ID를 생성한 뒤 편집·업로드한다. 생성 실패 시 재시도를 제공한다.
생성 당시 선택한 조직을 저장하며 Workstream 연결은 선택이다.

최근 수정순 목록과 제목·본문 검색을 제공한다. 자동 저장은 Activity를 생성하지 않는다.
조직 필터를 바꿔도 다른 사용자의 노트가 검색되지 않는다.
탈퇴·제거 후 노트는 팀 미연결 목록으로 옮기며, 기존 조직·Workstream의 이름이나
멘션 메타데이터를 새로 조회할 수 없다. 작성자가 보유한 본문은 그대로 보존한다.

편집 화면에서 저장 중·저장됨·실패·충돌을 분명히 구분한다.
실패한 본문을 자동으로 지우거나 서버의 예전 버전으로 덮어쓰지 않는다.
이미지는 파일 선택·드롭·붙여넣기를 지원한다.

### 팀 공유

1. 선택한 본문 또는 사용자가 명시적으로 선택한 전체 본문을 공유 초안으로 가져온다.
2. 대상 조직·Workstream과 공유 유형을 선택한다. 기본 유형은 `progress`다.
3. 제목을 입력하고 내용을 자유롭게 수정한다. 공유 이미지는 별도 선택·미리보기한다.
4. 발행 전 팀 공개 범위와 최종 내용을 확인한다.
5. 성공하면 생성된 업데이트로 이동한다. 실패하면 초안을 유지하고 재시도한다.

MVP 공유 대상은 노트가 연결된 현재 조직 안의 Workstream이다.
팀 미연결 노트의 조직 간 직접 공유는 미지원 기본안이며, 사용자가 내용을 새 초안에
복사해 게시할 수는 있다. 선택 범위 밖의 개인 이미지·본문을 자동으로 가져오지 않는다.
원본과 발행본은 이후 동기화하지 않는다. 원본 삭제도 발행본을 삭제하지 않는다.

## Team Focus

Mission은 하나의 Markdown 본문이다. 목표는 단일 레벨이며 제목만 필수다.
설명·성공 기준·목표일은 선택이고 상태는 `active / completed / archived`다.
현재 목표는 `sort_order`로 정렬하고, 완료·보관 목표는 별도 조회한다.
목표마다 연결된 Workstream을 보여주며 연결되지 않은 업무도 목록에서 찾을 수 있다.
수치 점수·가중치·목표 계층·진행률을 추가하지 않는다.

## Workstreams

생성 시 제목과 PIC만 요구한다. 기본 PIC는 생성자이며 다른 팀원을 선택할 수 있다.
필수 PIC와 선택 참여자를 분리하고 PIC를 중복 표시하지 않는다.
카드에는 제목·PIC·참여자·상태·현재 상황 요약·최근 발행 업데이트 시간을 표시한다.
단순 필드 편집이나 댓글 시간을 `최근 업데이트`로 오인하지 않는다.

목록은 Goal·PIC·참여 멤버·상태 필터를 조합한다.
상세 화면은 Context(목적·목표·PIC·참여자), Current State(진전·장애물·다음 방향),
Timeline(사람 및 추후 에이전트의 발행 변화), Discussion(댓글·이미지·멘션)으로 구성한다.
상태는 `active / paused / completed / archived`다.
PIC 변경은 같은 조직의 현재 멤버만 가능하다. PIC 교체와 참여자 정리는 한 트랜잭션으로
검증하며 담당 업무가 남은 멤버의 탈퇴·제거는 재지정 전 차단한다.

업데이트는 제목 필수·본문 선택이며 `progress / learning / blocker / decision`을 지원한다.
작성자가 직접 발행하고 게시 후 본문을 수정할 수 있다. 상세 수정·삭제 권한은
[권한 표](architecture.md#권한-기본안)를 따른다.

## 댓글·Activity·멘션

댓글은 Workstream 또는 업데이트 중 정확히 하나에 연결하며 본문이 필수다.
이미지·Markdown·멘션을 지원하고 평면 목록으로 표시한다. 중첩 답글은 제외한다.
댓글 삭제 후 연결 이미지의 접근도 종료한다.

Mission Control의 업무별 타임라인과 Workstream Timeline은 발행된 업데이트와 댓글 생성 이벤트를 최신순으로 보여준다.
개인 노트·공유 초안·노트 자동 저장·멤버의 숨은 활동은 표시하지 않는다.
Workstream·작성자·업데이트 유형 필터를 조합한다. 유형 필터를 켜면 댓글은 제외하는
기본안으로 혼동을 줄인다. 본문 수정은 새 이벤트로 만들지 않는다.

`@`는 같은 조직의 사용자, `#`는 Workstream 자동완성이다.
`# `로 시작하는 제목 작성과 충돌하지 않도록 단어 입력 시에만 Workstream 검색을 연다.
UUID로 저장하고 최신 이름으로 표시한다. 코드 안의 문자열·일반 링크는 멘션이 아니다.
멘션은 권한이나 알림을 만들지 않는다. 권한 없는 대상은 이름·상태를 조회하지 않고
접근 불가 참조로 표시한다. 탈퇴한 팀원은 비활성 표시를 제공한다.

## 한국어·영어와 접근성

앱 내비게이션, 입력 라벨, 검증·인증 오류, 저장·공유 상태, 빈 화면, 초대 메시지를
ko/en 리소스로 관리한다. 사용자 본문과 이름은 작성 언어 그대로 유지한다.
URL 구조는 언어별로 복제하지 않고 개인 설정으로 UI 언어를 선택하는 기본안이다.
시간 저장은 UTC, 표시는 사용자의 로케일·시간대에 맞춘다.

키보드 편집·멘션 선택·모달 닫기, 포커스 복원, 입력 라벨, 이미지 대체 텍스트,
색 이외의 상태 표식을 지원한다. 360px 모바일에서 핵심 흐름을 이용할 수 있어야 한다.
