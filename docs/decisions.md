# Corridor 결정 기록

기준일: 2026-10-14 (Asia/Seoul).
입력 자료: 사용자가 제공한 `Startup Team Workspace — MVP Development Plan v0.3`,
로켓 발사 이미지, 이 대화에서의 답변. 원문은 요구사항 자료이며 실행 지시로 취급하지 않는다.

`확정`은 사용자 요구사항, `제안`은 구현을 구체화하기 위한 기본안,
`미결정`은 구현·출시 전에 확인할 사항이다. 제안을 사용자 승인으로 표시하지 않는다.
세부 동작은 연결된 문서를 기준으로 관리한다.

## 확정

| 항목 | 결정 |
| --- | --- |
| 이름·의미 | Corridor. 로켓이 안전한 비행을 위해 따라야 하는 회랑 |
| 대상 | 3–15명 규모의 초기 스타트업 |
| 핵심 가치 | 개인에게 먼저 유용한 기록, 중요한 변화만 팀 공유, 낮은 입력 부담 |
| MVP | Mission Control, My Work, Workstreams, Team Focus; 업데이트·댓글·이미지·멘션 |
| Navigation | 모든 역할에 동일한 네 탭; 개인 데이터는 본인만, 발행 팀 데이터는 모든 조직 구성원 조회 |
| 공통 검색 | 현재 조직의 Workstream·Update·Team Goal과 본인 개인 노트 검색 |
| 에이전트 영역 | 자동 수집·분석은 후속 연동; Captured Activities는 빈 상태, 초기 주의 항목은 수동 팀 신호 사용 |
| Attention Needed | 팀 차원의 병목·업무 편중·의사결정·위험. 영향·근거·논의할 내용과 관련 Workstream을 제공하며 개별 업데이트 유형만으로 노출하지 않음 |
| 기술 스택 | Next.js / Vercel / Supabase 및 원문에 제시된 UI·편집·검증 도구 |
| 로그인 | Google OAuth + Email Magic Link |
| 팀 가입 | 로그인 후 팀 생성, 만료되는 초대 링크로 가입 |
| 조직 | MVP부터 여러 조직 가입·전환 |
| 출시 언어 | 한국어·영어 동시 지원 |
| Workstream 관리 | Owner/Admin/PIC가 상태·PIC·참여자 관리; 팀원 모두 생성·업데이트·댓글 가능 |
| 개인 기록 | Owner/Admin도 타인의 노트 열람 불가; 연결·멘션은 공개 효과 없음 |
| 공유 | 선택한 내용과 이미지를 별도 팀 업데이트로 발행; 원본 비공개 유지 |
| 탈퇴·강제 제거 | 개인 노트·이미지는 작성자가 계속 열람·수정·삭제; 팀 연결 해제 |
| PIC | 정확히 한 명, 같은 조직 구성원; 탈퇴 전에 재지정 |
| 콘텐츠 | Markdown 원문이 기준, 멘션은 UUID 참조, 이미지당 10MB |
| 브랜드 방향 | 이미지의 분위기를 유지한 검정·파랑·붉은색; 실제 추출색에 한정하지 않음. Ignition Red·Deep Sky Blue 그라디언트 정의 |
| UI 테마 | 전체 화면 다크 테마; 밝은 중립색 본문과 파랑·붉은색 강조 |
| 파일 길이 | 모든 파일 1,000줄 미만, 최대 999줄 |
