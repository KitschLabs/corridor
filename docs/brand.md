# Corridor 브랜드 가이드

브랜드 이름과 검정·파랑·붉은색 방향은 확정 요구사항이다.
아래 HEX와 역할은 제공 이미지의 밤하늘·불꽃 분위기를 유지하며 조정한 초기 팔레트다.
실제 픽셀 추출색을 그대로 사용할 필요는 없다.
전체 UI는 다크 테마로 제공한다. 로고·타이포·최종 자산은 아직 확정하지 않았다.

## 이름과 표현

Corridor는 로켓이 안전한 비행을 위해 따라야 하는 회랑에서 따온 이름이다.
이 제품은 팀의 모든 행동을 추적하는 대신 개인 기록과 공유할 방향을 연결한다.
제품 문구는 팀이 중요한 목표·발견·다음 방향을 이해하는 데 초점을 둔다.

기존 제품 원칙의 영문 표현을 유지한다.

> Share what matters, not everything you do.

로켓·궤적은 이름을 설명하는 참고 모티프다. 과한 발사 애니메이션, 우주 장식,
시뮬레이션 UI를 제품 기능으로 추가하지 않는다.

## 기본 팔레트

검정은 발사 직전의 어둠, 파랑은 깊은 하늘, 붉은색은 점화 에너지를 표현한다.
원본의 분위기를 참고하되 파랑과 붉은색은 화면에서 더 명확하게 보이도록 조정했다.

| 이름 | 토큰 | HEX | 권장 역할 |
| --- | --- | --- | --- |
| Corridor Black | `corridor-black` | `#080F15` | 화면 배경과 레이아웃의 구조 |
| Deep Sky Blue | `corridor-blue` | `#1769B3` | 주요 버튼, 선택 상태의 기준색 |
| Ignition Red | `corridor-red` | `#D63F32` | 강조, 중요한 변화, 경고 보조 |

흰색·회색은 읽기·표면·경계를 위한 중립색으로만 허용하며 네 번째 브랜드색으로 추가하지 않는다.

## 그라디언트

두 그라디언트는 135도 방향으로 어두운 시작점에서 밝은 끝점으로 이어진다.
중간의 55% 지점에 기본 브랜드색을 둔다. 끝점은 같은 색 계열의 변형이며 별도 브랜드색이 아니다.

| 이름 | 0% | 55% | 100% | 용도 |
| --- | --- | --- | --- | --- |
| Ignition Red | `#9C241D` | `#D63F32` | `#F47745` | 점화·추진의 에너지, 브랜드 강조·작은 포인트 |
| Deep Sky Blue | `#081E36` | `#1769B3` | `#3BA4E0` | 깊은 하늘에서 상승하는 느낌, 브랜드 배경·선택 강조 |

구현 시 사용할 CSS 정의:

```css
:root {
  --corridor-black: #080f15;
  --corridor-blue: #1769b3;
  --corridor-red: #d63f32;
  --corridor-gradient-ignition-red: linear-gradient(
    135deg, #9c241d 0%, #d63f32 55%, #f47745 100%
  );
  --corridor-gradient-deep-sky-blue: linear-gradient(
    135deg, #081e36 0%, #1769b3 55%, #3ba4e0 100%
  );
}
```

그라디언트는 브랜드 배경·장식·포인트에 사용한다. 긴 본문, 입력창, 상태 표시에
반복 적용하지 않는다. 주요 버튼은 단색을 기본으로 하며 그라디언트 애니메이션은 추가하지 않는다.

## UI 적용 기본안

주요 동작은 파랑 버튼과 흰색 글자로 표현한다. 검정 배경에 밝은 중립색 글자를 사용한다.
내비게이션, 네 탭, 상세 화면, 검색·설정·작성 모달과 입력 요소 모두 다크 테마를 적용한다.
OS 테마와 무관하게 동일하게 표시하며 별도 테마 전환은 제공하지 않는다.

| UI 역할 | HEX |
| --- | --- |
| 화면 배경 | `#080F15` |
| 카드·모달·입력 표면 | `#111C27` |
| 보조 표면·hover | `#1B2938` |
| 본문·제목 | `#E5EDF5` |
| 보조 글자 | `#9AAABC` |
| 경계 | `#283747` |
| 링크·선택 글자 | `#79BFFF` |
| 경고 글자 | `#FF998E` |

밝은 파랑·붉은색은 어두운 표면에서 가독성을 확보하는 브랜드색의 변형이다.
붉은색은 제한적으로 사용하고 모든 카드·상태를 붉게 칠하지 않는다.
상태는 색과 함께 문구·아이콘으로 구분하며 progress/learning/blocker/decision에
각각 새로운 브랜드색을 추가하지 않는다.

초기 contrast 계산은 불투명 sRGB와 순백 `#FFFFFF` 기준이다.
실제 화면의 표면·hover·disabled·투명도를 적용한 뒤 다시 검증한다.

| 조합 | 계산 contrast | 적용 |
| --- | --- | --- |
| 파랑 배경 / 흰색 글자 | 5.66:1 | 주요 버튼 후보 |
| 검정 배경 / 흰색 글자 | 19.28:1 | 다크 배경의 고대비 텍스트 기준 |
| 붉은 배경 / 흰색 글자 | 4.55:1 | 단색 강조 버튼 후보; 투명도 적용 시 재검증 |
| 두 그라디언트의 밝은 끝점 / 흰색 글자 | 각각 약 2.77:1 | 일반 텍스트 배경으로 사용하지 않음 |

붉은 강조는 아이콘·선·표식으로 쓰고 설명 텍스트는 밝은 중립색으로 배치한다.
실패 상태를 붉은색만으로 전달하지 않는다. 작은 글자의 대비를 위해 팔레트
조합을 검증하고 배경·텍스트 역할을 정한다. 그라디언트 위 글자는 단색 패널에 배치하거나
글자가 놓이는 전체 영역의 대비를 따로 확인한다. 중간 기본색의 대비만으로 통과 처리하지 않는다.

## 자산과 공개 사용

첨부 이미지는 현재 색상 참고 자료다. 사용 권리가 확인되지 않았으므로 서비스의
공개 hero·로고·OG 이미지로 그대로 배포하지 않는다.
이번 문서화에서는 원본 이미지를 저장소에 복사하거나 새 로고를 생성하지 않는다.
글꼴 라이선스·로고·최종 자산은 UI 제작 전에 결정한다.
