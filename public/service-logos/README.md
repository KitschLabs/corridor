# Service logos

GitHub, Google Drive, and Instagram SVGs are sourced from the Iconify Logos
collection (https://github.com/iconify/icon-sets/blob/master/json/logos.json),
which uses SVG Porn artwork (https://github.com/gilbarbara/logos).
Brand marks remain the property of their respective owners and identify external links.
GitHub is rendered white on dark backgrounds; the other marks retain their colors.
